# Battery Manufacturing

The complete automotive battery manufacturing process — from raw lead to finished product.

---

| Step | Process | Key Output |
|------|---------|------------|
| 1. [Grid Casting](grid-casting.md) | Pb-Ca-Sn alloy grids formed | Lead grid |
| 2. [Plate Pasting](plate-pasting.md) | Active material applied to grids | Pasted plate |
| 3. [Curing](curing.md) | Controlled temp/humidity conversion | Cured plate |
| 4. [Formation](formation.md) | Electrochemical activation | Active battery |
| 5. [Final Testing](final-testing.md) | 100% quality verification | Ship-ready battery |
