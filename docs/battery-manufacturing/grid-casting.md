# Grid Casting

## 1. Definition

Production of lead alloy grids — the current collector and structural framework for battery plates.

## 2. Process

Gravity casting: molten Pb-Ca-Sn alloy poured into water-cooled book molds. Expanded metal: cast strip is slit and stretched into diamond-mesh grid. Continuous Concast: cast on rotating drum, then rolled and punched. Chengguang uses automated gravity casting for SLI and heavy-duty grids.

## 3. Quality Control

Grid wire thickness, paste adhesion surface area, corrosion resistance, current distribution uniformity. IATF 16949 controlled process.
