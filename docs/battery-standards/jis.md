# JIS Standard Battery Standard

Japanese Industrial Standard — dominant battery standard across Asia, Africa, Middle East, and Oceania. JIS model numbers encode performance class and dimensions (e.g., 65D26). Terminal: T1 (small/large post). Hold-down: B00 (top frame). Polarity: [0] right-positive.

## Key Characteristics

| Attribute | JIS | DIN | BCI |
|-----------|:---:|:---:|:---:|
| Region | Asia, Africa, ME | Europe, Africa, ME | North America |
| Terminal | T1 post | Standard post | SAE post / side |
| Hold-down | B00 (top frame) | B13 (bottom rail) | Various |
| Polarity | [0] Right-positive | [0] Right-positive | Various |
| Code System | Performance + size | 5-digit numeric | Group number |
