# DIN Standard Battery Standard

Deutsches Institut fur Normung — European battery standard. DIN codes are 5-digit numeric. Terminal: standard post. Hold-down: B13 (bottom rail). Polarity: [0] right-positive. DIN batteries are typically shorter and wider than JIS equivalents.

## Key Characteristics

| Attribute | JIS | DIN | BCI |
|-----------|:---:|:---:|:---:|
| Region | Asia, Africa, ME | Europe, Africa, ME | North America |
| Terminal | T1 post | Standard post | SAE post / side |
| Hold-down | B00 (top frame) | B13 (bottom rail) | Various |
| Polarity | [0] Right-positive | [0] Right-positive | Various |
| Code System | Performance + size | 5-digit numeric | Group number |
