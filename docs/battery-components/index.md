# Battery Components

Every automotive battery is built from five core components. Understanding each component's material, design, and function is essential for evaluating battery quality.

---

| Component | Function |
|-----------|----------|
| [Lead Grid](lead-grid.md) | Current collector and mechanical support for active material |
| [Separator](separator.md) | Electrically insulates positive from negative plates |
| [Electrolyte](electrolyte.md) | Ion conductor — enables electrochemical reaction |
| [Battery Case](battery-case.md) | Container, cover, and terminal seals |
